Why MTGJSON-slim?

The official MTGJSON dataset is comprehensive. This slim edition removes less relevant shopping, sealed-product, booster, source deck-list, translation-table and narrative data while preserving verified card and token printings, identities, rules text, multi-face relationships, rulings, legalities and useful search indexes.

Who is it for?

AI agents, deckbuilding tools, collection managers, card-search apps, deck validators and swap advisors that need smaller, dependable SQLite or JSON card data. All retained card values come from the verified official source; original non-English printing records remain included.

What it is not: a standalone deckbuilder, AI model, game simulator or complete rules engine. Integrating tools must supply their own deckbuilding and rules logic. Read more about the data selection and limitations.
